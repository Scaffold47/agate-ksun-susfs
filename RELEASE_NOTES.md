# First public build

This is the first public build of my Xiaomi 11T agate kernel setup.

It includes KernelSU Next 3.2.0 legacy with manual hooks and SusFS 1.5.5. The kernel was built from source and tested on my own device before publishing.

The tested setup is crDroid 12.10 on Android 16 with Linux 4.14.336.

KernelSU root works, manual hooks are active and SusFS initializes correctly during boot. SusFS userspace communication was also tested after the system finished booting.

Use this build at your own risk. Keep a working boot image from the exact ROM version you are using before flashing anything.

Other ROMs, firmware bases and Android versions have not been tested yet.
